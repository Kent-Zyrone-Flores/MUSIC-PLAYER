# Music Player

A local music player built with React, TanStack Start, and Tailwind CSS.

## Features

- Browse and play local music files (MP3, WAV, OGG, FLAC, M4A)
- Video playback support (MP4, WebM, MOV, MKV)
- Playlist management
- Favorites and recently played
- Search functionality
- Volume control, shuffle, and repeat
- Import music files from your computer

## Development

```sh
npm install
npm run dev
```

## Built with

- TanStack Start
- React
- Tailwind CSS
